# market-visualiser
Interactive market data visualiser for analysing simulations and historical backtest results, including price charts, trades, positions, PnL, and portfolio metrics.

# packages
pandas      for loading CSVs and handles time-series data
numpy       for fast numerical calculations
matplotlib  for basic charts
yfinance    historical stock data downloader
# tools
pytest      for testing backtester logic
ipykernel   for Jupyter notebooks
fastapi     Python backend API
uvicorn     for running the FastAPI server
